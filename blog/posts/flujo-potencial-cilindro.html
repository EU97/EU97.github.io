Si entras a la portada de este sitio verás partículas que fluyen de izquierda a derecha y se abren alrededor de la figura central. No es un efecto aleatorio: cada partícula se mueve con la velocidad que da una de las soluciones más clásicas de la mecánica de fluidos, el flujo potencial alrededor de un cilindro.

La idea: sumar dos flujos simples

En un fluido ideal (sin viscosidad y sin remolinos) los flujos se pueden sumar. Si a un flujo uniforme de velocidad U le añadimos un doblete —una fuente y un sumidero infinitamente juntos— aparece una línea de corriente cerrada con forma de círculo de radio R. Esa línea se comporta como la pared de un cilindro: el fluido la rodea sin atravesarla.

u = U · (1 − R²(x² − y²) / r⁴)   ·   v = −2 U R² x y / r⁴

Con esas dos expresiones basta para mover miles de partículas en el navegador: en cada cuadro, cada partícula avanza (u·dt, v·dt).

Qué se ve

  • Dos puntos de estancamiento, al frente y atrás del cilindro, donde la velocidad es cero.
  • La velocidad máxima es 2U justo arriba y abajo del cilindro. Por eso en la portada las partículas cambian a naranja ahí: el código colorea las que superan 1.55 U.
  • Simetría perfecta entre el frente y la parte trasera.

Lo que este modelo no dice

Esa simetría es justamente su límite. Si la presión es igual adelante y atrás, la fuerza neta sobre el cilindro es cero: es la paradoja de d'Alembert. En un fluido real la viscosidad forma una capa límite que se desprende, aparece una estela y con ella el arrastre.

Un modelo ideal sirve para entender; para decidir hay que medir.

Por eso en proyectos reales —como la validación de un UAV convertible en la University of Southampton— los modelos numéricos (CFD) se correlacionan con ensayos en túnel de viento antes de confiar en ellos. El flujo potencial es el primer escalón: rápido, exacto dentro de sus supuestos y perfecto para explicar.

El código

// velocidad del flujo potencial alrededor de un cilindro (cx, cy, R)
const vel = (x, y) => {
  const dx = x - cx, dy = y - cy, r2 = dx * dx + dy * dy;
  if (r2 < R * R) return [0, 0];           // dentro del cilindro
  const k = (R * R) / (r2 * r2);
  return [U * (1 - k * (dx * dx - dy * dy)), -U * 2 * k * dx * dy];
};
